# יום ההורים: מסע אל תוך הלב ❤️

מדריך בעברית לילדים על מה שאבא עושה בעבודה: מהנדס מערכות בג'ונסון אנד ג'ונסון מדטק, בתחום ה־EP (אלקטרופיזיולוגיה, החשמל של הלב).

המדריך בנוי בהשראת האתר [Space-explanation](https://github.com/Yanik1983/Space-explanation): אותו סגנון חללי, הסברים קצרים לילדים, "הידעתם?", מילון מושגים וחידון.

## הרצה
הדף סטטי לגמרי. פותחים את `index.html` בדפדפן, או מריצים:

```bash
python3 -m http.server 8000
```

## עריכה
כל הטקסטים נמצאים ישירות ב־`index.html`. אפשר להתאים אותם לתפקיד ולמוצרים המדויקים שלך.
